# Zapret GUI 2.42.0

Обновление встроенных компонентов, стратегий и интерфейса.

- Комплект zapret синхронизирован с [Flowseal 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2): добавлены новые UDP/TLS/QUIC-файлы и обновлены списки. Сам winws.exe и библиотеки WinDivert совпадают с предыдущим комплектом.
- Встроенный Telegram-прокси обновлён с 1.8.1 до [tg-ws-proxy 1.10.1](https://github.com/Flowseal/tg-ws-proxy/releases/tag/v1.10.1). Добавлен комплект сертификатов certifi.
- Все 20 прежних пресетов обновлены из оригинальных BAT-файлов; добавлены `general (ALT13)` и `general (EXP)`. Всего 22 стратегии.
- Интерфейс получил светлую тему по умолчанию, мягкие карточки, более ясную навигацию и статусы. Сохранённые настройки темы продолжают действовать.
- Исправлено сохранение настроек из разных частей приложения, чтобы изменения интерфейса не затирали параметры Telegram-прокси.
- Усилена проверка загружаемых списков и ZIP-обновлений. При наличии SHA-256 в GitHub проверяется контрольная сумма архива.
- При обновлении пресетов сохраняются пользовательские стратегии с уникальными именами и резервная копия прежнего JSON.
- Исправлены отмена автоподбора, формирование команды службы и завершение фоновых задач Telegram-прокси. Секрет прокси скрывается в диагностическом архиве.

## Установка

Скачайте `ZapretControl.zip`, распакуйте всю папку и запустите `ZapretControl.exe`. Папка `_internal` должна оставаться рядом с EXE. Python отдельно не требуется.

## Проверка

Локально проходят 90 тестов и 4 вложенных сценария, включая оригинальные тесты tgproxy. Проверены состав Windows x64 сборки, контрольные суммы компонентов и целостность архива. Работа обхода зависит от провайдера; реальное подключение и запуск EXE с правами администратора в рамках подготовки релиза не проверялись.
