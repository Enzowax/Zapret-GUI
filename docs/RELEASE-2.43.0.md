# Zapret GUI 2.43.0

## Надёжность обхода

- Обычная остановка больше не завершает все процессы `winws.exe` и не удаляет
  драйвер WinDivert: GUI управляет только запущенным им процессом или своей
  службой.
- Авто-поиск не трогает `winws.exe`, запущенный другой программой, и не считает
  стратегию рабочей, если её временный процесс завершился раньше проверки.
- Watchdog не возвращается к стратегии, уже упавшей в текущем цикле.
- При ошибке переустановки службы выбранная стратегия не меняется в настройках.

## DNS, статус и удобство

- DoH меняет настройки DNS только после проверки PowerShell; при ошибке
  восстанавливает уже изменённые адаптеры и сохраняет исходные DNS только после
  успешного применения.
- На главном экране показываются понятное состояние обхода, время и результат
  последней проверки связи. Для запуска без прав администратора есть кнопка
  повторного запуска с повышением прав.
- В списке стратегий отображаются краткие метки протоколов и десинхронизации;
  добавлена команда возврата к последней полностью проверенной стратегии.
- Архив поддержки больше не включает сохранённые адреса DNS, секрет прокси и
  локальный путь пользователя.

## Проверка

`pytest tests -q` и проверка ошибок исполнения Ruff (`E9,F`) проходят; снимки
светлой, тёмной и упрощённой тем обновлены локальным предпросмотром.
