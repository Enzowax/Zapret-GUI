# Zapret GUI 2.44.0

- Ускорено создание расширенного интерфейса: страницы открываются по мере необходимости, тяжёлые разделы строятся порциями. Журнал меньше задерживает кнопки и перерисовку.
- Стоп отменяет устаревшие запуски и восстановление. Поиск сохраняет предыдущие результаты при отмене и восстанавливает прежний режим работы.
- Виджет связи сохраняет состояние при смене темы, отвергает ответы от прежнего запуска и различает ошибку, недоступность и устаревшие данные. Показание — время TLS-соединения, не задержка голосового Discord.
- Восстановление учитывает каждый выбранный сервис, проверяет кандидатов и откатывает неудачную замену. Повторы запуска ограничены задержками 5, 15 и 45 секунд.
- Поиск сравнивает покрытие и надёжность перед задержкой, использует три независимых подробных измерения и продолжает перебор после неудач первых кандидатов.
- Импорт, обновление списков и запись исключений защищены проверками и атомарной заменой. Обновление приложения требует SHA-256.
- DoH сохраняет первоначальные настройки и режим DNS; при неполном откате данные восстановления остаются. Для старого снимка без режима требуется выбор пользователя.
- Проверено совпадение 22 стратегий с Flowseal zapret 1.10.2. Пользовательские исключения действуют и в применимых профилях Google.
- Telegram-прокси: применимые изменения upstream v1.10.2, ограниченное ожидание после HTTP 429 и явные импорты.
- Заключительный проход: ранний Стоп отменяет отложенный автозапуск; отмена и ошибка сохранения поиска возвращают прежнюю таблицу; сбой остановки процесса показывается явно и не теряет ссылку на процесс.
- Падение winws во время замера и отменённая серия больше не дают успешный результат. Потеря интернета в ходе подбора не портит пул; снятый с проверки сервис не запускает восстановление.
- В «Диагностике» добавлена аварийная остановка всех процессов `winws.exe`, независимо от запустившего их приложения. Обычная кнопка «Стоп» по-прежнему управляет только запуском Zapret-GUI.
- Завершение приложения ожидает очистку в фоновом потоке. SHA-256 повторно проверяется перед распаковкой, отчёты включены в совместимую с самообновлением структуру.

Подробные проверки и оставшиеся испытания описаны в VALIDATION-2.44.0.md. Финальный релизный комплект подготовлен локально; реальная сеть, драйвер, DNS и Telegram media требуют отдельной проверки перед публикацией.
