# Zapret GUI 2.45.0

## Компоненты

- Ядро zapret обновлено до Flowseal zapret-discord-youtube 1.10.3: новый фейк `tls_clienthello_www_sferum_ru.bin`, свежие `list-exclude.txt`, `list-google.txt` и IPSet, обновлённый `utils/test zapret.ps1`. Аргументы всех 22 стратегий не изменились.
- Telegram-прокси обновлён до tg-ws-proxy v1.11.1: H2-транспорт медиа через Cloudflare, переработанный пул WebSocket-соединений, backoff для TCP-фолбэка. Локальные патчи перенесены, добавлен новый: отмена задач прокси на Python 3.11 больше не теряется.

## Новое

- В настройках появилась карточка «Порты игрового фильтра»: TCP и UDP порты задаются вручную, как в service.bat 1.10.3. Старый формат файла настроек тоже понимается.

## Исправления

- «Подобрать настройку» в простом режиме и мастер первого запуска теперь сразу запускают найденную стратегию, даже если обход был выключен.
- Перед самообновлением свой `winws.exe` останавливается, а после перезапуска поднимается снова с тем же пресетом. Выход для обновления больше не зависает.
- DoH выключается и при пропавших сетевых адаптерах, в журнал пишется предупреждение.
- Watchdog при первой проверке только запоминает сеть и не отменяет текущие операции.
- Чтение и запись конфига повторяются, если файл кратко занят другим процессом Windows.
- Плановая проверка списков повторяется каждые 6 часов, а не только при старте. Исправлено сообщение «Списки сохранены» при ошибке.
